# SiLaundry - Sistem Informasi Manajemen Laundry Kiloan

**SiLaundry** adalah aplikasi desktop berbasis Python (`tkinter`) yang dirancang untuk mengelola operasional transaksi harian pada usaha laundry kiloan secara terstruktur.

## Fitur Utama

- Pencatatan pesanan masuk dan kalkulasi biaya otomatis berdasarkan berat (kg) dan paket layanan.
- Pembaruan status pengerjaan cucian (`Proses` / `Selesai`).
- Pencarian data pesanan berdasarkan Nomor Nota maupun Nama Pelanggan.
- Pengurutan data transaksi berdasarkan harga atau berat.
- Penyimpanan permanen menggunakan berkas tabular `CSV`.
